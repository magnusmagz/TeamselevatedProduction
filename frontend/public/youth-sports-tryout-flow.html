7

  • ✓ Team placement details
  • ✓ Season fee amount
  • ✓ Accept/Decline deadline (48h)

Recreational vs. Competitive Tryout Flow

🏃 Recreational Program

✓ No tryout required
✓ All players placed on teams
✓ Single-step registration
✓ Pay fee → Assigned to team
✓ Skills assessment for placement only
Flow:
Register → Pay → Team

🏆 Competitive / Travel

✓ Tryout required
✓ Limited roster spots
✓ Two-step registration
✓ Tryout → Offer → Accept → Pay
✓ Evaluation determines selection
Flow:
Tryout Reg → Evaluate → Offer → Accept → Pay → Team

Tryout Program Configuration

Program Settings

  • • Linked Season Program
  • • Tryout Date(s) & Location
  • • Tryout Fee ($25-50)
  • • Season Fee (post-acceptance)
  • • Roster Spots Available
  • • Offer Expiration (24-72 hrs)

Evaluation Criteria

  • • Technical Skills (1-5)
  • • Tactical Awareness (1-5)
  • • Physical Fitness (1-5)
  • • Attitude/Coachability (1-5)
  • • Game Intelligence (1-5)
  • • Custom criteria as needed

Notifications

  • • Tryout confirmation email
  • • Tryout reminder (24hr before)
  • • Offer letter email
  • • Waitlist notification
  • • Rejection / redirect to rec
  • • Acceptance confirmation
