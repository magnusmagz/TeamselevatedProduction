# Development Notes

## Important: Do NOT use MAMP

This project does NOT use MAMP. All development should be done with:
- **Frontend**: React dev server (npm start) on port 5173
- **Backend**: Heroku (production) at https://teamselevated-backend-0485388bd66e.herokuapp.com
- **Local Backend** (if needed): Port 8889

## API Configuration

All components should use this pattern:
```typescript
const API_URL = process.env.REACT_APP_API_URL || 'http://localhost:8889';
```

## Environment Variables

See `.env` file for production API URL.
