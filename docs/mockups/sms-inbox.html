Why the auto-reply is shown

The system already answered Cathy before any human saw this. If the thread hid that, an admin would write a reply that contradicts it. Once a person can answer, that auto-reply's wording has to change — it currently claims the number isn't monitored.

Needs reply is the default view

Four of these seven are the same question — where is the invite? The list sorts for what's unanswered, not what's newest, because the job here is clearing a queue.

The number is stated, not assumed

A reply goes out from the club's own number, so the composer says which one and what the text will cost in segments. The same rules as Broadcast, in the place the message is written.

Context comes from the athlete

A phone number alone is not a person. Each thread names the crew member, their athlete and team, so the admin answers knowing who is asking — and can open the profile or send the invite without leaving the thread.
